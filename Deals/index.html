        Promo code questions

        How do I use a code on Laters.com?

        Copy the code from the listing, search your route, and pick a flight. Enter the code in the promo field at checkout before you choose a payment method, then select the matching pay later provider. The discount shows in the price breakdown before you pay.

        Why was my code rejected?

        The usual reasons are a minimum spend that the fare does not reach, a country the offer does not cover, or a first time customer condition you do not meet. Each listing shows its minimum spend and conditions before you copy.

        Are these offers really live?

        Every offer that reaches this page has been through our own review queue before publishing. Nothing here is scraped from a provider's site or a third party. If an offer's end date passes, it stops rendering everywhere on the site, including this page, automatically.

        Can I stack two codes?

        No. One promotional code applies per booking. Where an offer applies automatically, no code is needed and the discount is handled for you at checkout.

        Why do some providers show no offers?

        Not every provider has a live promotion running at all times. When a provider has nothing live, its page still shows the standing plan structure and fees so it is useful even without a code.
